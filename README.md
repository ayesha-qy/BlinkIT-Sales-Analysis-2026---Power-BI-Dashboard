# 🛒 BlinkIT Grocery Sales Analysis — Power BI Dashboard

An end-to-end Power BI project that analyzes sales performance across BlinkIT grocery outlets — from raw data to a fully interactive, drill-down dashboard covering sales by item type, fat content, outlet size, outlet location, and outlet establishment year.

![Dashboard Preview](images/dashboard_full.png)

---

## 📌 Project Overview

BlinkIT ("India's Last Minute App") operates grocery outlets of varying size, type, and location tier across the country. This project builds a single-page Power BI report that lets a business stakeholder answer, at a glance:

- How much are we selling, and how does that break down by product and outlet?
- Which item categories and fat-content segments drive the most revenue?
- Does outlet size, location tier, or outlet age correlate with sales performance?
- How do average sales, item count, and customer rating vary by outlet type?

The report is fully cross-filterable — clicking any visual (e.g., an outlet size segment) filters every other visual on the page.

## 🗂️ Dataset

**File:** `BlinkIT Grocery Data.xlsx`
**Size:** 8,523 rows × 12 columns — one row per item listed at a given outlet.

| Column | Type | Description |
|---|---|---|
| `Item Identifier` | Text | Unique product code (1,559 distinct products across all outlets) |
| `Item Type` | Text | Product category — 16 categories (Fruits & Vegetables, Snack Foods, Household, etc.) |
| `Item Fat Content` | Text | Low Fat / Regular — recorded inconsistently in the raw file (see *Data Cleaning* below) |
| `Item Weight` | Decimal | Product weight; ~17% of rows are missing this value |
| `Item Visibility` | Decimal | Share of total display area allocated to the item in-store |
| `Outlet Identifier` | Text | Unique store code (10 outlets) |
| `Outlet Establishment Year` | Integer | Year the outlet opened (2011–2022) |
| `Outlet Size` | Text | Small / Medium / High |
| `Outlet Location Type` | Text | Tier 1 / Tier 2 / Tier 3 city classification |
| `Outlet Type` | Text | Grocery Store / Supermarket Type 1 / Type 2 / Type 3 |
| `Sales` | Decimal | Revenue generated by that item at that outlet |
| `Rating` | Decimal | Customer rating for the item (1.0–5.0) |

**Source & credit:** the file name and 12-column schema correspond to a public "BlinkIT Grocery Data" dataset that circulates on Kaggle for Power BI practice — several listings note it's <cite index="9-1">a fictional dataset built for a grocery/retail analytics scenario</cite> rather than real BlinkIT sales data, effectively a re-themed version of the classic BigMart Sales schema with an added `Rating` column. At least one Kaggle listing bundles this <cite index="8-1">exact `BlinkIT Grocery Data.xlsx` file together with a matching `Blinkit Projects for Sales.pbix`</cite>, confirming the dataset's use as a standard Power BI teaching project. The dashboard build itself follows the step-by-step approach taught in the *Data Tutorials* YouTube walkthrough "Amazing Real Time Power BI Project | Start to End Analysis | Power BI for Beginners," adapted here and documented in this repo.

## 🔄 Project Workflow

The dashboard was built following a standard end-to-end BI delivery process:

1. **Requirement Gathering / Business Requirements** — defined which charts stakeholders needed and what each one had to answer (full list below).
2. **Data Walkthrough** — reviewed all 12 columns to understand grain (one row = one item at one outlet), ranges, and categories.
3. **Data Connection** — imported `BlinkIT Grocery Data.xlsx` into Power BI via Get Data → Excel.
4. **Data Cleaning / Quality Check** — standardized inconsistent category labels. `Item Fat Content` contained five raw variants (`Low Fat`, `low fat`, `LF`, `Regular`, `reg`) that collapse into two clean categories (**Low Fat**, **Regular**); `Item Weight` had missing values that needed a null-handling strategy; a few outlets also showed inconsistent `Outlet Size` tagging across records for the same `Outlet Identifier`, flagged for a follow-up cleaning pass.
5. **Data Modeling** — kept a single flat fact table (no separate dimension tables were required given the grain), with categorical columns set as the basis for slicers and cross-filtering.
6. **Data Processing** — applied Power Query steps (trim/whitespace, replace values, data type fixes) to lock in the cleaned categories before loading.
7. **DAX Calculations** — built the core KPI measures (below) that drive every card, chart, and table on the page.
8. **Dashboard Layouting** — planned a single-page layout: KPI cards top-left, trend chart top-right, category breakdown center, and slicer/filter panel on the far left inside the BlinkIT-branded sidebar.
9. **Charts Development and Formatting** — built each visual to its required chart type (donut, bar, stacked column, line, funnel map, matrix) and applied consistent BlinkIT yellow/green theming.
10. **Dashboard / Report Development** — assembled all visuals into the final interactive report with cross-filtering enabled across every chart.
11. **Insights Generation** — interpreted the finished dashboard to produce the takeaways in the *Key Insights* section below.

## 📐 Key DAX Measures

The four headline KPI cards and every breakdown on the page are driven by four core measures:

```dax
Total Sales   = SUM('BlinkIT Grocery Data'[Sales])

Average Sales = AVERAGE('BlinkIT Grocery Data'[Sales])

No of Items   = COUNTROWS('BlinkIT Grocery Data')

Average Rating = AVERAGE('BlinkIT Grocery Data'[Rating])
```

> Note: **No of Items** counts total item-at-outlet records (8,523), not distinct products — the catalog itself contains 1,559 unique `Item Identifier` values spread across 10 outlets.

## 💡 Key Insights

- **Supermarket Type1 is the clear revenue driver**, contributing 65.5% of total sales ($787.55K) from 5,577 of the 8,523 items — more than the other three outlet types combined.
- **Low Fat items nearly double Regular items in sales** ($776K vs. $425K), suggesting demand skews toward the "healthier" labeled segment regardless of outlet.
- **Medium-sized outlets outsell both Small and High-size outlets** ($507.90K vs. $444.79K and $248.99K), indicating outlet footprint alone doesn't guarantee higher sales — High-size outlets underperform despite their larger format.
- **Tier 3 locations generate the most revenue** (39% of total), ahead of Tier 2 (33%) and Tier 1 (28%) — smaller/emerging markets are outperforming Tier 1 cities in this dataset.
- **Outlet establishment year shows a spike around 2018** (~$205K vs. a ~$130K per-year baseline), which traces back to two outlets launching that year rather than a single outlet outperforming — worth calling out explicitly so the trend chart isn't misread as one outlet's growth.
- **Fruits & Vegetables and Snack Foods are the top two categories**, together accounting for roughly 30% of total sales across all 16 item types.
- **Average sales per item is remarkably consistent** across all outlet types (~$140–$142), meaning the revenue gap between outlet types is driven almost entirely by item volume, not by higher-value baskets.
